Glance 是 Umami 和 Plausible 的移动端与桌面端客户端。所有站点一眼尽览，还有真正的仪表盘，帮您看懂站点上发生的一切。

站点对比

站点交叉对比

多个站点并排查看：每个站点一条曲线，外加总数。1 到 6 行，可来自一个或多个 Umami 账户。

再加一个“来自”或“不含来自”某个域名的筛选，就能看到您的站点之间互相送去了多少访客。另有一个专门的视图，汇总站点间互相导流的访客。

事件

追踪每个事件

每个事件一条曲线、一种颜色，可按属性筛选：套餐 = pro，金额 ≥ 20。

可以计数、计算比率，也可以查看某个属性各个值的分布及其随时间的变化。

漏斗

看清用户在哪流失

2 到 8 个步骤，显示每一步的访客数和流失率。

两个步骤之间的时间间隔由您设定。仅限 Umami。

留存

衡量用户留存

接入指标数据源：您站点上的一个小型 API，由令牌保护。

Glance 随即显示次日、7 日和 30 日留存、新增账户数，以及您的站点提供的任何指标。计算始终在您自己的数据库上完成。

阅读指标数据源文档（英文）

预测

预见月底数据

在“本月”和“今年”下，曲线会以橙色虚线延伸，并给出预计总数。

预测基于近 7 天的水平和每周的规律。

实时与小组件

实时数据，直达主屏幕

每个站点此刻的在线访客，按活跃度排序。

iOS 和 Android 小组件，可显示总数或指定站点。

多设备

所有设备，同步随行

iPhone、iPad、Android、Mac 和 Windows，支持浅色与深色模式。在 Mac 和 Windows 上，站点列表在左，详情在右。

加密二维码，一次扫描即可迁移配置；也可在设备间使用端到端加密同步（可选，一次性购买）。

常见问题

Glance 是什么？

Glance 是免费开源的移动端与桌面端客户端，用来查看您的 Umami 和 Plausible 统计数据。它把您所有的站点汇集到一个清晰的应用中——平滑曲线、实时数据和小组件——而且始终不离开您自己的分析实例。

Glance 免费吗？

免费：应用免费且开源（MIT 许可证），无需账户、无需订阅，站点数量不限。唯一收费的是一项可选功能——Glance Sync，即配置的加密备份——一次性购买。

支持哪些分析工具？

Glance 目前支持 Umami 和 Plausible，包括自托管实例。Fathom 已在计划中。您可以同时追踪多个账户和多个服务商，合并在同一视图中。

Glance 支持哪些平台？

Glance 支持 iOS（App Store）、Android（Google Play）、macOS（Homebrew 或 DMG）和 Windows。应用使用 Flutter 开发，是真正的跨平台应用。

我的数据会发送给第三方吗？

不会。Glance 直接与您的 Umami 或 Plausible 实例通信，只读访问，没有中间服务器，也没有追踪。您的凭据加密保存在设备的钥匙串中。

什么是 Glance Sync？

一项付费的可选功能（一次性购买），可备份您的账户和分组，并在其他设备上恢复。配置在设备上加密后才会发送：服务器只保存一段无法读取的数据。不使用它，Glance 也能完全在本地运行，二维码迁移依然免费。

可以按客户或项目分开我的站点吗？

可以，使用分组。分组是一个查看范围：总数、曲线和实时数据只统计该组的站点。在主页即可在各个分组之间切换。

Glance 支持自托管实例吗？

支持。无论您的 Umami 或 Plausible 是自托管还是云端版，Glance 都通过您的 URL 和 API 密钥直接连接，服务器端无需任何配置。
